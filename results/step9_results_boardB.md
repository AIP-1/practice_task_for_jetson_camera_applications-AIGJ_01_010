## 9-2 시간 정보 활용 (기본 모드, smooth)

- 처음엔 만세가 잘 안 잡힘: 0.6초 중 60% 이상 같은 판정이어야 바뀌는데, 한쪽 손목을 자주 놓쳐 만세 비율이 60%를 못 넘음 → 카메라에서 더 물러나 두 손끝이 화면에 들어오게 함 (필요하면 pose_model.py의 KP_CONF 0.5 → 0.3)
- 손 흔들기는 1.5초 안에 좌우 방향을 2번 이상 바꾸고, 한 번에 어깨 너비의 15% 이상 움직여야 함 → 한 팔을 머리 옆까지 높이 들고 크고 빠르게 흔드니 WAVE로 인식
- 최종: 만세, 한팔들기, 손 흔들기(WAVE) 모두 따로 안정적으로 인식. 손 흔들기는 9-1에서 안 되던 것이 시간 패턴으로 해결됨.

## 9-6 GRU 학습 (window 30)

- 최고 검증 정확도 0.989

| 정답 \ 예측 | arms_crossed | clap | idle | wave |
| --- | --- | --- | --- | --- |
| arms_crossed | 25 | 0 | 0 | 0 |
| clap | 0 | 18 | 1 | 0 |
| idle | 0 | 0 | 26 | 0 |
| wave | 0 | 0 | 0 | 17 |

검증 데이터는 같은 녹화의 뒷부분이라 점수가 높게 나온다. 실제 성능은 실시간으로, 녹화에 참여하지 않은 사람으로 확인해야 한다.

### 실시간 확인 (`python pose_app.py --model models/action.pt`)

| 학습 설정 (특징 표준편차 최소값) | idle(가만히) | wave | clap | arms_crossed |
| --- | --- | --- | --- | --- |
| README 원본 (1e-6) | ✗ 가만히 있어도 wave로 셈 | 잘 안 됨 | ✓ 잘 됨 | - |
| 0.1 | ✓ | ✓ | ✗ 잘 안 됨 | - |
| 0.03 | ✓ | ✓ | △ 가끔 인식 | ✓ |
| 0.03 + 박수 30초 추가 녹화 (최종) | ✓ | ✓ | ✓ | ✓ |

- 원인 추정: 녹화 때 얼굴을 화면 밖으로 빼서 얼굴 관련 특징(정면 점수 등)이 항상 0이었고, 표준편차가 거의 0이라 실시간에 조금만 달라져도 정규화 값이 폭주함. 최소값을 크게 하면 이 폭주는 막지만 박수를 구분하는 작은 차이도 같이 둔해짐 → 중간값 0.03이 가장 나았음.
- 검증 정확도(98.9%)는 같은 녹화의 뒷부분으로 잰 것이라, 실시간 성능은 이보다 낮다.

## 9-3 행동 녹화 + 9-6 행동 모델

녹화 (얼굴 보이게, 카메라 눈높이, 라벨당 10회): passing 213줄, glance 309줄, interested 1101줄.

- 설명서 설정(`--window 80 --stride 10`): passing·glance 0 윈도, interested 학습 11 / 검증 0 → 학습 불가 (한 번 지나가는 데 1.5~2초라 80프레임이 안 됨)
- 설명서 안내("4초가 안 걸리면 --window를 줄인다")에 따라 `--window 15`로 학습

| 라벨 | 학습 윈도 | 검증 윈도 |
| --- | --- | --- |
| glance | 16 | 0 |
| interested | 75 | 11 |
| passing | 8 | 0 |

- 최고 검증 정확도 0.364. 단, 검증 윈도가 interested 것뿐이라 이 점수는 interested만 채점한 것 (11개 중 4개 맞음, 7개는 passing으로 예측)
- 해석: 검증은 각 녹화의 뒤 20%라서, 관심 있음 녹화의 끝부분(돌아서 걸어 나가는 장면)이 들어감. 1초 창으로 보면 이 장면은 실제로 "지나감"처럼 보이므로 passing 예측이 꼭 틀린 것은 아님. 실제 성능은 실시간으로 확인.

### 실시간 확인 (`--behavior --model models/action.pt --model models/behavior.pt`)

- 지영 팀 확인: 4가지 장면 모두 기대한 패턴이 나옴 (요약 줄 기준)
- 한 사람의 판정이 한글(규칙)과 영어(모델: passing / glance / interested) 사이를 오감. 모델은 5프레임마다 다시 판단하고 확률 0.7(`ML_TH`) 이상일 때만 결과를 덮어쓰기 때문에, 모델 확신이 0.7을 넘었다 내려갔다 할 때마다 규칙 ↔ 모델로 바뀜
  - 예: #4 지나감 → glance → 힐끗 봄 → passing, 요약은 "체류 3초, 정면 2초 → 힐끗 봄"
- 동작별 횟수도 같은 행동이 한글·영어로 나뉘어 집계됨 (지나감 5 + passing 3 등)
